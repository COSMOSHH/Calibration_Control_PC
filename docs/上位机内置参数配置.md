# 上位机内置参数配置

第一版界面按 UI0/UI1 保持简洁，以下参数不在界面中显示，统一在 `src/thz_calibration/config.py` 中维护。

| 参数 | 配置项 | 当前值 |
|------|--------|--------|
| 下位机运行模式 | `device_mode` | `simulated` |
| 频谱仪运行模式 | `spectrum_analyzer_mode` | `simulated` |
| 频谱仪 VISA 地址 | `visa_address` | `TCPIP::10.18.18.2::INSTR` |
| 信号源控制模式 | `signal_source_control_mode` | `manual` |
| 本振源 VISA 地址 | `lo_signal_source_visa_address` | `TCPIP::0.0.0.0::INSTR` |
| 中频源 VISA 地址 | `if_signal_source_visa_address` | `TCPIP::0.0.0.0::INSTR` |
| 中频/本振核算表 | `signal_source_frequency_plan_path` | `docs/说明文档/中频和本振频率核算表.xlsx` |
| 默认测试频点 | `frequency_ghz` | 212 GHz |
| 默认波束指向角 | `beam_angle_deg` | 30 deg |
| 相位扫描起点 | `phase_start_deg` | 0 deg |
| 相位扫描终点 | `phase_end_deg` | 354.375 deg |
| 相位扫描步长 | `phase_step_deg` | 5.625 deg |
| 馈源数量 | `feed_count` | 4 |
| 内置幅度值 | `default_amplitude` | 0.12，仅用于模拟/旧逻辑兼容，不进入 STM32 发送 payload |
| 每点稳定等待时间 | `settle_time_ms` | 500 ms |
| 每点采样次数 | `sample_count` | 3 |
| 串口默认端口 | `serial_port` | `COM1` |
| 串口默认波特率 | `serial_baudrate` | 9600 |

功率判定策略固定为多次采样平均值，保存单位为 uW。

新项目下发给 STM32 的 `SET_FEEDS` payload 只包含 `feed_id`、`phase_deg`、`enabled`，不再包含幅值/幅度字段。

波束指向角用于转台电机控制和数据记录，当前不进入 STM32 发送 payload。

运行模式说明：

- `device_mode = "simulated"`：使用虚拟下位机，适合无硬件调试。
- `device_mode = "serial"`：使用真实串口连接 STM32。
- `spectrum_analyzer_mode = "simulated"`：使用模拟频谱仪数据。
- `spectrum_analyzer_mode = "visa"`：通过 pyvisa/VISA 连接真实频谱仪。
- `signal_source_control_mode = "manual"`：默认手动控制信号源，只在点击 UI0 全局“确认”后提示本振源/中频源应设置的频率和功率。
- `signal_source_control_mode = "auto"`：点击 UI0 全局“确认”后，根据校准频率查表得到本振源和中频源频率，并向两个 VISA 信号源下发 `:FREQuency:FIXed`、`:POWer:LEVel`、`:OUTPut:STATe ON`。

数据保存说明：

- 输出目录默认为项目根目录下的 `output/`。
- Excel 模板目录为 `docs/馈源间相位校准数据保存格式/`。
- 导出文件固定使用模板同名文件，不追加时间戳后缀；重复测试会覆盖同名 Excel。
- Feed2~Feed4 校准时会读取已保存表格中的前序最佳相位，后续馈源扫描保持前序馈源相位不变。
- 最大功率点会在导出的 Excel 表格中标红。
- 完成 Feed4 测试后，会自动生成 `CalData_MultiFeed_MultiBeamDir_212to224_6bit.xlsx` 汇总表。

日志说明：

- UI0 校准扫描每成功发送一个相位点，会在终端打印一行 `CE1~CE4` 片选打开/关闭状态和 `Feed1~Feed4` 的当前相位值。
- 终端日志只打印片选状态和相位组合，不打印完整 HEX 帧，避免校准过程输出过长。

串口端口也可以通过启动参数传入，例如：

```powershell
python run_calibration_ui.py --serial-port COM3
python run_config_ui.py --serial-port COM3
```
